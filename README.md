--------------------------------------------------------------------
1. HOW TO RUN PHENOPLOT ON LINUX
--------------------------------------------------------------------
1. Extract 'PhenoPlot_v1.0_Linux.zip'.
2. Open your terminal inside the extracted folder.
3. Make sure the executable has execution permissions by running:
       chmod +x PhenoPlot/PhenoPlot
4. Launch the application:
       ./PhenoPlot/PhenoPlot

--------------------------------------------------------------------
2. CORE FEATURES
--------------------------------------------------------------------
- Interactive 2D PCA Space Map: Fixed reference space visualization.
- Phenotype Match Engine: Multi-dimensional 13D distance & similarity scoring.
- Source / Target Workspace: Clean coordinate block management.
- Midpoint Simulator: Synthesize intermediate phenotype coordinates.

--------------------------------------------------------------------
3. SAFETY & VERIFICATION
--------------------------------------------------------------------
PhenoPlot is compiled directly from Python source using PyInstaller.
- No root / sudo privileges required.
- Does not modify system directories.
- Runs completely offline without tracking or external network calls.
