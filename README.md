Thank you for using PhenoPlot! 

PhenoPlot is a desktop suite designed for global phenotype space 
mapping, custom coordinate management, and multi-dimensional 
proximity calculations.

--------------------------------------------------------------------
1. QUICK START (Linux 64-bit)
--------------------------------------------------------------------
To run PhenoPlot on Linux:

1. Extract the downloaded archive:
      unzip PhenoPlot_v1.0_Linux.zip

2. Open your terminal and navigate to the application folder:
      cd PhenoPlot_v1.0_Linux/dist/PhenoPlot

3. Grant execution permissions to the binary:
      chmod +x PhenoPlot

4. Launch the application:
      ./PhenoPlot

--------------------------------------------------------------------
2. KEY FEATURES
--------------------------------------------------------------------
* Interactive 2D PCA Space Map
  Visualizes target coordinates against a fixed reference grid using 
  a top-5 power-4 weighted proximity model.

* 13D Phenotype Match Calculator
  Ranks morphological similarity percentages and multi-trait distance 
  metrics instantly.

* Vahaduo-Style Workspace
  Easily edit and swap coordinate blocks using standard PhenoPlot 
  bracket notation: `"Sample_Name": [1.0000, 4.0000, ...]`.

* Midpoint Simulator
  Synthesize synthetic intermediate coordinates between any two 
  reference populations or custom samples.

--------------------------------------------------------------------
3. SECURITY & PRIVACY
--------------------------------------------------------------------
* PhenoPlot runs 100% offline. It makes no external network calls 
  and tracks zero user data.
* Does not require root or sudo permissions to run.
* Uses an encrypted database container (.ppc) for fast, secure local 
  data access.
